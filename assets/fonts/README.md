# CampusMincho

介面標題使用 Noto Serif CJK TC 的 Regular 與 SemiBold 字重，來源為 [Noto CJK 官方字體專案](https://github.com/notofonts/noto-cjk/tree/main/Serif/OTF/TraditionalChinese)，以 [SIL Open Font License 1.1](OFL-NotoSerifCJK.txt) 授權。

這兩份 OTF 為 FontTools 製作的介面字元子集，內部名稱已改為 CampusMincho。合計約 1.10 MiB，包含應用現有 Dart 介面文字、日期、曜日、數字與標點。完整來源字體與下載網址分別為：

- `NotoSerifCJKtc-Regular.otf`：<https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/TraditionalChinese/NotoSerifCJKtc-Regular.otf>
- `NotoSerifCJKtc-SemiBold.otf`：<https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/TraditionalChinese/NotoSerifCJKtc-SemiBold.otf>

字體僅用於固定介面標題及日期索引。課程名稱、教師、教室等使用系統黑體並保留原文，避免介面字體子集影響匯入內容的完整顯示。
