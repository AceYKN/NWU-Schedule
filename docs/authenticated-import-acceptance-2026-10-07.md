## 现场发现与修复

1. **首次打开冲突选择弹层空白。** 未作选择时 `SegmentedButton` 的 `selected` 为空，但组件默认不允许空集合，触发断言。允许初始未选择状态；仍要求全部字段明确决策后才能应用。新增生产弹层组件回归测试，实际模拟器验证两种选择均可保存。
2. **列表标题缺失会借用下拉选项识别错误学年。** 已识别的 `#kblist_table` 必须使用自身学年/学期标题；标题不完整直接无法解析。仅没有该列表的旧结构保留页面级元数据回退。
3. **整行缺失能产生表面合法但不完整的 Preview。** 当前页面同时渲染列表和网格；增加两种视图的课程节点数量一致性检查。删掉完整单行或增加重复节点会产生错误、禁用确认，并保留本地数据。网格仅用于完整性检查，不作为解析回退。安全诊断仅增加两项数字计数。
4. **强制停止绕过退出清理，会保留登录 Cookie。** 每次新导入会话开始前，排队执行平台会话清理，再加载入口；不只依赖 `dispose()`。最终 APK 上验证已登录强制停止后重开仍要求登录。

## 实际请求与返回结构

以下来自已认证 WebView 的实际请求，非其他学校文档、fixture 或猜测。认证字段、请求头中的 Cookie 和个人值未落盘。

共同查询参数 `gnmkdm=N253508`；入口另有 `layout=default`。观察到的请求全部 HTTP 200。POST 为表单编码 `application/x-www-form-urlencoded;charset=UTF-8`，返回 JSON 为 `application/json;charset=UTF-8`。

| 方法与路径 | 表单字段 | 返回结构 |
| --- | --- | --- |
| GET `/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html` | 无 | `text/html;charset=UTF-8` HTML 外壳，原始响应尚无列表/网格 |
| POST `/jwglxt/kbcx/xskbcx_cxRsd.html` | `xnm,xqm,xqh_id` | 数组，观察 3 个时段；条目含 `rsdm/rsdmc/rsdzjs/xqh_id` 等 |
| POST `/jwglxt/kbcx/xskbcx_cxRjc.html` | `xnm,xqm,xqh_id` | 数组，观察 11 个节次；条目含 `jcmc/qssj/jssj/njxh` 等 |
| POST `/jwglxt/kbcx/xskbcx_cxXsgrkb.html` | `xnm,xqm,kzlx,xsdm,kclbdm,kclxdm` | 对象，含 `kbList/sjkList/xsxx` 等 |

`xnm` 为学年起始年份的数字字符串；本次查询 2024、2025、2026。第一学期 `xqm=3`，第二学期 `xqm=12`，已通过实际查询与渲染标题对应。`kzlx` 是字符串；本次 `xsdm/kclbdm/kclxdm` 为空字符串；`xqh_id` 是数字字符串。未从这些值推断未测试的业务枚举。

主响应观察到这些顶层字段：

```text
qsxqj, xsxx, sjkList, sjfwkg, xqjmcMap, xskbsfxstkzt,
rqazcList, kbList, xsbjList, zckbsfxssj, sfxkkg, djdzList,
kblx, sfxsd, jfckbkg, xqbzxxszList, xkkg, sxgykbbz,
jxhjkcList, xnxqsfkz
```

与当前周课表相关的 `kbList` 条目字段映射如下；以下均观察为字符串，不保留实际课程或人员值：

| JSON 字段 | 对应含义 / 本次核对方式 |
| --- | --- |
| `kcmc` | 课程名；统一展示空白，剔除自修标记课程 |
| `xqj` | 星期数字字符串；对应 `xq_rowspan_<1..7>` |
| `jcs` / `jc` | 节次信息；对应 `jc_<weekday>-<start>-<end>` |
| `zcd` | 周次文本；对应日历图标字段 |
| `xm` | 此处是教师；与 `xsxx.XM` 的学生姓名语义不同 |
| `xqmc` / `cdmc` | 校区 / 教室；对应地点图标字段 |
| `xnm` / `xqm` | 学年 / 学期编码 |
| `kch_id` / `jxb_id` | 课程 / 教学班 ID；本次存在，同学期重复查询保持一致 |

ID 的观察仅限此账号与本次查询，不证明跨账号、跨学期或长期稳定性；产品尚未依赖原始 API ID。详细结构文件记录数组条目字段并集、观察到的类型及嵌套对象结构，数组示例取首项；这不是所有可能响应的正式 schema。

实际流程是 **HTML 外壳 → 异步 JSON → 页面脚本渲染 DOM → App DOM 提取**，修正旧记录中由表单 action 推断“服务器直接返回列表”的说法。没有把主导入器改成直接消费 API JSON。
