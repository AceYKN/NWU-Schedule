```powershell
./tool/run_android.ps1 -Device emulator-5558 -Flutter E:/flutter/bin/flutter.bat -Adb E:/Android/Sdk/platform-tools/adb.exe
```

该脚本构建正式入口，只执行 `adb install -r`。空间不足、签名不匹配或版本不兼容时停止，不卸载或清除数据。普通 `flutter run` 自带的卸载重试逻辑不受应用代码控制。
