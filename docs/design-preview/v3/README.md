# 第三版：精簡和風預覽

> 歷史留檔。目前第四版已加入月曆、設定與細節文案。

直接修改真實 Dart 頁面並在 Android API 35 模擬器執行。首頁與週課表是本輪預覽範圍，其他頁面沿用現有實作。

- 移除大日期索引、刊頭、竪排印章、重複標題與底部編號，恢復單行頁首及圖示導覽。
- 介面使用「月曜日、火曜日、水曜日、木曜日、金曜日、土曜日、日曜日」「時間割」「本日」「次回授業」「授業中」「設定」。
- 暖白底、墨綠文字、少量朱紅，明朝體僅用於介面標題、日期及導覽。
- 首頁優先顯示教室，完整資料仍可點開課程查看。課程名稱、教師、校區、教室資料保留原文。
- 尚未接入正式主題設定。`officialThemes` 名稱、配色及設定維持原始定義，只有獨立 `lib/dev/design_preview.dart` 入口注入預覽樣式。
